# Zamtel Loans App

A lightweight loan application landing page for Zambia with:
- a loan amount slider as the primary interaction
- applicant details for names and email
- phone number verification flow with OTP
- secure PIN creation and confirmation
- responsive styling for mobile and desktop

## Run locally

From the project folder:

```bash
python3 -m http.server 8000
```

Then open:

http://localhost:8000

## Files

- `index.html` – app structure
- `styles.css` – mobile-first styling and layout
- `script.js` – slider logic, validation, and OTP interactions
